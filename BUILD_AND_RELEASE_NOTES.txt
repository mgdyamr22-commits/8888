تعليمات بناء ونشر حزمة الاستضافة (بعد تحديثات نظام إدارة المستخدمين)
=========================================================================

هذا المصدر يحتوي على كل التعديلات المُنفَّذة فعليًا (وتم التحقق منها):
- src/services/userApiService.ts (ملف جديد)
- App.tsx (محدّث)
- components/UserAdmin.tsx (محدّث)
- types.ts (محدّث)

خطوات البناء (تحتاج جهاز فيه Node.js واتصال إنترنت لمرة واحدة فقط):
--------------------------------------------------------------------
1. افتح Terminal / CMD جوه مجلد المشروع ده.

2. ثبّت المكتبات (مرة واحدة فقط، أو لو عدّلت package.json):
   npm install

3. ابنِ حزمة الاستضافة:
   npm run build:hosting

4. هيتولد مجلد جديد اسمه:
   hosting_package/
   
   ده هو نفسه اللي ترفعه بالكامل لاستضافة Hostinger (بديل الحزمة القديمة).

5. تأكد إن قاعدة البيانات فيها الجدول users بنفس الأعمدة المستخدمة في
   api/auth/users.php (id, username, password_hash, role, full_name,
   email, phone, branch_id, specialty, is_active...) — لو الباك إند
   اللي رفعته قبل كده شغال، الجدول أصلاً موجود ومفيش داعي لأي تعديل.

ملاحظة: لو حصل أي خطأ أثناء npm install بسبب نسخة Node قديمة، تأكد إنك
مستخدم Node.js 18 أو أحدث.

بعد البناء، ابعتلي أي رسالة خطأ لو ظهرت أثناء npm run build:hosting
وأنا هساعدك تحلها فورًا.
