
# AutoStock Manager Pro - منصة كاريان الرقمية

نظام إدارة مخزون السيارات المتكامل المصمم لسطح المكتب (Desktop Edition)، يعمل كقاعدة بيانات مستقلة ومشفرة تماماً لضمان أمان بيانات المؤسسات.

## 🚀 المميزات الرئيسية
- **إدارة المخزون المتقدمة**: تتبع السيارات بالماركة، الموديل، رقم الهيكل (VIN)، وحالة التجير.
- **نظام الحماية Hardware ID**: تفعيل البرنامج يتم بربطه عتادياً بجهاز واحد عبر منصة كاريان.
- **تقارير احترافية**: توليد كشوفات جرد جاهزة للطباعة (PDF) بوضع Landscape وتكرار العناوين.
- **تعدد الصلاحيات**: دعم كامل للأدوار (مدير، موظف، مندوب) مع نظام حجز للمناديب.
- **قاعدة بيانات مستقلة**: يعمل النظام بدون إنترنت مع إمكانية تصدير واستيراد القاعدة يدوياً.

## 🛠 المتطلبات التقنية
- **Electron JS**: لتشغيل النظام كبرنامج سطح مكتب.
- **Vite + React**: لسرعة الأداء وتجربة المستخدم السلسة.
- **Tailwind CSS**: لتصميم عصري ومتجاوب.
